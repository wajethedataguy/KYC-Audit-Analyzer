# KYC Exceptions Generator

A robust, desktop-based ETL and audit automation tool for KYC audit workflows.

## Features
- Automated data ingestion from multiple MIS sources
- 107+ rule-based KRI exception detection
- Data cleaning & normalization
- Control effectiveness evaluation
- Audit-ready Excel reporting
- User-friendly desktop UI

## Project Structure
```
KYC_Viewer/
    KYC_Viewer/           # Main package (source code)
        logic/            # KRI logic scripts
    assets/               # Icons, images
    screenshots/          # UI screenshots
    tests/                # Unit tests
    requirements.txt      # Dependencies
    README.md             # Project overview
```
